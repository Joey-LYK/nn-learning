一本面向数学零基础读者的中文神经网络教材。从"什么是函数"讲起，
到亲手实现反向传播与神经网络库，最后纵览 CNN、RNN、Transformer。

> 算法逐行对应、同样零依赖、可编译运行，详见[前言的说明](00-前言与学习指南.md)。
