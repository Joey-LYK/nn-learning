# 第1章 函数与导数

> 本章学习目标：
> 1. 能说清"函数就是输入对应输出"的含义，并能代入数字算出 $f(x)$
> 2. 能看懂函数图像，知道图像上一点 $(x, f(x))$ 代表什么
> 3. 能用"汽车速度表"的类比解释导数是什么
> 4. 会用三条求导法则（常数、线性、幂函数）求出简单函数的导数
> 5. 知道链式法则"外层导数乘内层导数"，并会套用到两层复合函数

## 从一个例子开始

你开车上高速，瞟了一眼仪表盘：速度表显示 100 公里/小时。

这个数字是什么意思？它不是"你已经跑了多远"，而是"你此刻跑得有多快"。

现在想一想：如果你能把你从出发到现在的"总里程"画成一条随时间变化的曲线，那么速度表上的 100，其实就是这条曲线在当前时刻的"陡峭程度"。

里程是一个函数，速度是这个函数的变化快慢。而"描述变化快慢"这件事，在数学里有个专门的名字——导数（derivative）。

这一章你只需记住一个核心：**导数就是函数在某一点的变化快慢**。它是整本书最重要的工具，后面训练神经网络靠的梯度下降，本质上就是在反复计算和使用导数。

## 什么是函数

函数（function）就是一台机器：你丢给它一个数，它还给你一个数。

```
  输入 x ──► [ 函数机器 ] ──► 输出 f(x)
```

比如你写下一个函数：

$$f(x) = 2x + 1$$

它表达的意思是：不管输入什么，都先乘以 2，再加 1。

代入几个数试试，每一步都能拿计算器验算：

- 输入 $x = 3$：$f(3) = 2 \times 3 + 1 = 6 + 1 = 7$
- 输入 $x = 0$：$f(0) = 2 \times 0 + 1 = 1$
- 输入 $x = -1$：$f(-1) = 2 \times (-1) + 1 = -1$

符号 $f(x)$ 读作"F of X"，$f$ 是这台机器的名字，括号里的 $x$ 是输入。你也可以用别的字母，比如 $g(x)$、$h(x)$，就像给不同的机器起不同的名字。

生活里的函数到处都是：

| 场景 | 输入 | 输出 |
|---|---|---|
| 自动售货机 | 投入的钱 | 掉出的饮料 |
| 打车计费 | 里程数 | 车费 |
| 电饭煲 | 米和水的量 | 煮熟的时间 |

为什么神经网络离不开函数？因为**一个神经元本身就是一台这样的机器**：输入一个数 $x$，它算出 $z = wx + b$，再加工一下得到输出。全书记号表里你已经见过 $z = wx + b$ 了——它就是一个函数，$w$ 和 $b$ 是这台机器里两个可以拧的旋钮。

## 函数的图像

把函数算出来的结果画在坐标纸上，你就能"看见"这台机器的性格。

横轴是输入 $x$，纵轴是输出 $f(x)$。每算一对数，就在纸上点一个点。点连起来，就是函数的图像。

还是 $f(x) = 2x + 1$，先列个表：

| $x$ | 计算过程 | $f(x)$ |
|---|---|---|
| -2 | $2\times(-2)+1$ | -3 |
| -1 | $2\times(-1)+1$ | -1 |
| 0 | $2\times 0+1$ | 1 |
| 1 | $2\times 1+1$ | 3 |
| 2 | $2\times 2+1$ | 5 |

画出来是一条直线：

```
  f(x)
    5 |                    *
    3 |              *
    1 |        *
   -1 |   *
   -3 |*
      +--+--+--+--+--+--► x
     -2 -1  0  1  2
```

这条线向右上方爬升。每往右走 1 格，就向上爬 2 格——这个"爬升的快慢"是个固定值 2，它正好是 $f(x) = 2x + 1$ 里 $x$ 前面的那个系数。

再看一个会弯的函数：$g(x) = x^2$（$x$ 的平方，即 $x \times x$）。

| $x$ | -2 | -1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|
| $g(x)$ | 4 | 1 | 0 | 1 | 4 | 9 |

```
  g(x)
    9 |                         *
    4 |  *                 *
    1 |     *           *
    0 |        *  *  *
      +--+--+--+--+--+--+--► x
       -2 -1  0  1  2  3
```

这条曲线像个碗。注意看：它在 $x=0$ 附近几乎是平的，在 $x=3$ 附近却非常陡。也就是说，**曲线的陡峭程度在不同位置是不一样的**。

怎么精确描述"某一点有多陡"？这就是导数要回答的问题。

## 更多函数例子：一台机器一个性格

在往下讲之前，多见几台"机器"，培养手感。

**常数函数** $f(x) = 5$：不管输入什么，输出永远是 5。画出来是一条水平线。

```
  f(x)
    5 | *  *  *  *  *
      +--+--+--+--+--► x
```

**递减直线** $f(x) = -x + 3$：每往右走 1 格，下降 1 格。

| $x$ | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| $f(x)$ | 3 | 2 | 1 | 0 |

**绝对值** $f(x) = |x|$：负数取相反数，正数不变。画出来是一个"V"字，在 $x = 0$ 处有个尖角。这个尖角很重要，后面会再遇到它。

判断一台机器是不是函数，只有一条标准：**一个输入只能对应一个输出**。售货机投 5 元出一瓶可乐，是函数；如果同一台机器投 5 元有时出可乐有时出矿泉水，它就不是函数。

## 斜率：直线的陡峭程度

先解决直线，因为它最简单。

斜率（slope）的定义：

$$\text{斜率} = \frac{\text{竖直方向的变化}}{\text{水平方向的变化}}$$

用两个点来算。$f(x) = 2x + 1$ 上取点 $(0, 1)$ 和 $(2, 5)$：

$$\text{斜率} = \frac{5 - 1}{2 - 0} = \frac{4}{2} = 2$$

换两个点再算，取 $(-1, -1)$ 和 $(1, 3)$：

$$\text{斜率} = \frac{3 - (-1)}{1 - (-1)} = \frac{4}{2} = 2$$

结果一样。直线的斜率处处相同，所以一次函数 $f(x) = ax + b$ 的斜率就是 $a$。

用日常的话说：斜率 2 就是"每向右走 1 步，上升 2 步"。斜率越大，坡越陡；斜率是负数，说明是下坡。

## 导数：曲线上某一点的"瞬时斜率"

曲线麻烦了：它每一点的陡峭程度都不同。怎么办？

思路非常朴素：**在曲线上取两个靠得很近的点，算它们连线的斜率。两点越靠越近，这条连线的斜率就越接近该点处的"真实陡峭程度"。**

```mermaid
graph LR
    A[取两个点<br>算连线斜率] --> B[让两点靠近]
    B --> C[斜率趋于稳定值]
    C --> D[这个稳定值<br>就是导数]
```

动手算一下。取 $g(x) = x^2$，我们想求 $x = 2$ 这一点的陡峭程度。在 $x = 2$ 附近取另一个点 $x = 2 + h$，$h$ 是两点的水平距离：

- 第一个点：$(2,\ 4)$
- 第二个点：$(2+h,\ (2+h)^2)$

连线斜率：

$$\frac{(2+h)^2 - 4}{h} = \frac{4 + 4h + h^2 - 4}{h} = \frac{4h + h^2}{h} = 4 + h$$

这里用到了 $(2+h)^2 = 4 + 4h + h^2$，你可以展开 $(2+h)\times(2+h)$ 自己验证。

关键一步：让 $h$ 越来越小，逼近 0。

| $h$ | 斜率 $= 4 + h$ |
|---|---|
| 1 | 5 |
| 0.1 | 4.1 |
| 0.01 | 4.01 |
| 0.001 | 4.001 |

斜率稳稳地逼近 4。于是我们得出结论：曲线 $x^2$ 在 $x = 2$ 处的"瞬时陡峭程度"是 4。

**这个稳定值 4，就叫函数在 $x = 2$ 处的导数。** 记作 $f'(2) = 4$，右上角的撇号读作"prime"。

回到开头的汽车类比：里程曲线是 $f(t)$，速度表读数就是导数 $f'(t)$。里程是"你跑了多远"，导数是"你此刻跑多快"。

用同样的方法可以推出 $g(x) = x^2$ 在任意点 $x$ 处的导数（把上文的 2 换成 $x$ 重新算一遍即可）：

$$g'(x) = 2x$$

看，这个公式和刚才的数值完全吻合：$g'(2) = 2 \times 2 = 4$。

## 导数的几何意义：切线的斜率

两点连线叫割线。当两点无限靠近，割线就贴成了曲线在该点的**切线**（tangent line）——只接触那一条曲线、刚好"擦过"该点的直线。

```
  g(x)                __--
    9 |           __--
    4 |      *---            ← 割线：连接 (2,4) 和远处一点
      |     /  \
    1 |    /    ---__
      |   /         切线：贴着 (2,4) 恰好擦过
    0 +--/------------► x
        2
```

所以导数有一个等价说法：**函数在某点的导数 = 图像在该点切线的斜率。**

$x^2$ 在 $x = 2$ 处导数是 4，意味着过点 $(2, 4)$ 画一条刚好贴合曲线的直线，这条直线的斜率是 4。你甚至可以把切线方程写出来：过 $(2, 4)$、斜率 4，即 $y = 4x - 4$（验证：$x = 2$ 时 $y = 8 - 4 = 4$，确实过该点）。

切线视角回答了一个实用问题：**在这一点附近，函数大约往哪走、走多快。** 梯度下降里每一步"朝哪迈"，本质上就是在用切线方向做局部预测。

## 三条最常用的求导法则

"求导数"简称"求导"。上面那种从定义硬算的方法太慢，数学家总结出了现成的法则，你记住这三条就够本书用了。

**法则一：常数的导数是 0。**

$$f(x) = 5 \quad\Rightarrow\quad f'(x) = 0$$

道理：常数画出来是一条水平线，不升不降，变化快慢当然是 0。

**法则二：线性函数的导数就是斜率。**

$$f(x) = ax + b \quad\Rightarrow\quad f'(x) = a$$

例子：$f(x) = 3x + 2$，则 $f'(x) = 3$。

**法则三：幂法则（power rule）。**

$$f(x) = x^n \quad\Rightarrow\quad f'(x) = n\,x^{\,n-1}$$

意思是：指数搬到前面当系数，指数本身减 1。

- $f(x) = x^2 \Rightarrow f'(x) = 2x^1 = 2x$（和上文推导一致）
- $f(x) = x^3 \Rightarrow f'(x) = 3x^2$

另外加一条组合规则：**函数相加，导数也分别相加；常数倍可以提到导数外面。**

例子：$h(x) = 3x^2 + 2x + 1$，逐项求导：

- $3x^2$ 的导数是 $3 \times 2x = 6x$
- $2x$ 的导数是 $2$
- 常数 $1$ 的导数是 $0$

所以 $h'(x) = 6x + 2$。

## 链式法则：函数套函数怎么办

有时一台机器的输出会接着喂给下一台机器，这叫复合函数（composite function）。

```mermaid
graph LR
    X[x] --> G[机器 g] --> U[u = g x] --> F[机器 f] --> Y[y = f u]
```

比如 $y = (x + 1)^2$。拆开看：内层机器 $g(x) = x + 1$ 先加 1，外层机器 $f(u) = u^2$ 再平方。

链式法则（chain rule）说：

$$y' = f'(g(x)) \times g'(x)$$

口诀：**外层的导数，乘内层的导数。**

套进例子：

- 外层 $f(u) = u^2$，导数 $f'(u) = 2u$，代入 $u = x+1$ 得 $2(x+1)$
- 内层 $g(x) = x + 1$，导数 $g'(x) = 1$

$$y' = 2(x+1) \times 1 = 2(x+1)$$

验算一下：把 $(x+1)^2$ 展开得 $x^2 + 2x + 1$，直接求导得 $2x + 2 = 2(x+1)$。两种方法答案一致，链式法则可信。

再练一个带系数的：$y = (2x + 1)^3$。

- 外层 $f(u) = u^3$，导数 $f'(u) = 3u^2 = 3(2x+1)^2$
- 内层 $g(x) = 2x + 1$，导数 $g'(x) = 2$

$$y' = 3(2x+1)^2 \times 2 = 6(2x+1)^2$$

注意内层导数 2 不能丢。新手最常犯的错就是只求了外层、忘了乘内层。

为什么要学它？因为**神经网络就是一长串"函数套函数"**：输入经过第一层、第二层、第三层……每一层都是一台机器。将来要算"最终误差对第一层某个旋钮的导数"，靠的就是链式法则一层层往回乘。这也是"反向传播（backpropagation）"的全部数学本质。

## 动手实验

下面三个实验只用 Python 标准库，保存成 `.py` 文件直接运行即可。

**实验一：画出函数图像（文字版）。** 这段代码把 $f(x) = x^2$ 的值算出来，用星号在终端里画出曲线，让你"看见"碗形。

```python
def f(x):
    return x * x

for x_ten in range(-20, 21, 2):   # x 从 -2 到 2，步长 0.2
    x = x_ten / 10
    y = f(x)
    stars = int(y * 5)            # 纵轴值换算成星号数量
    print(f"x={x:+.1f} | " + "*" * stars)
```

预期输出：你会看到星号数量先从多变少（$x$ 从 -2 到 0），再从少变多（$x$ 从 0 到 2），呈一个对称的"V"字收拢再张开——这正是碗形的侧影。

**实验二：数值逼近导数。** 这段代码用本章"两点靠近"的思想，让计算机替你逼近 $x^2$ 在 $x = 2$ 处的导数。

```python
def f(x):
    return x * x

x = 2
h = 1.0
for _ in range(8):
    slope = (f(x + h) - f(x)) / h   # 两点连线的斜率
    print(f"h = {h:.6f}  近似导数 = {slope:.6f}")
    h = h / 10                      # 每次把距离缩小 10 倍
```

预期输出：近似导数依次打印 5.0、4.1、4.01、4.001……逐步逼近 4。这正是我们在正文表格里手算过的过程，现在计算机替你跑了一遍。

**实验三：亲手验证幂法则。** 这段代码用数值方法分别逼近 $x^2$ 和 $x^3$ 在 $x = 3$ 处的导数，再和幂法则的公式结果对比。

```python
def numerical_derivative(f, x):
    h = 0.0001
    return (f(x + h) - f(x)) / h

x = 3
print("x^2 数值导数:", round(numerical_derivative(lambda t: t**2, x), 2))
print("x^2 公式导数 2x =", 2 * x)
print("x^3 数值导数:", round(numerical_derivative(lambda t: t**3, x), 2))
print("x^3 公式导数 3x^2 =", 3 * x * x)
```

预期输出：两行数值分别约为 6.0 和 27.0，与公式 $2x$、$3x^2$ 在 $x=3$ 处的结果 6 和 27 完全对上。

**实验四：数值验证链式法则。** 这段代码用数值逼近算 $y = (x + 1)^2$ 在 $x = 2$ 处的导数，和链式法则的结果 $2(x+1) = 6$ 对比。

```python
def numerical_derivative(f, x):
    h = 0.0001
    return (f(x + h) - f(x)) / h

复合函数 = lambda x: (x + 1) ** 2
x = 2
print("数值导数:", round(numerical_derivative(复合函数, x), 3))
print("链式法则 2(x+1) =", 2 * (x + 1))
```

预期输出：两个数字都约为 6。你亲手验证了"外层导数乘内层导数"在数值上成立。

## 常见误区

**误区：导数是"函数在某一点的值"。**
真相：导数是"函数在那一点的变化快慢"，跟函数值本身是两回事。$x^2$ 在 $x=2$ 处的函数值是 4，导数碰巧也是 4，但在 $x=1$ 处函数值是 1、导数是 2，两者并不相等。

**误区：斜率大就是函数值大。**
真相：陡峭程度和高度无关。悬崖底部的一条缓坡，海拔很低但可能很平；小土包顶上也可能非常陡。$x = 100$ 处 $x^2$ 的值高达 10000，但 $-x$ 这条线在同样高度附近斜率始终是 $-1$。

**误区：求导就是把式子抄一遍再改个符号。**
真相：求导有明确规则。本章只用三条：常数导数为 0，线性函数导数是斜率，幂法则"指数搬到前面、指数减 1"。遇到没见过的函数，先拆成熟悉的形式再求导。

## 小结与下一章预告

本章要点：

1. 函数是一台"输入一个数、输出一个数"的机器，神经元的 $z = wx + b$ 就是函数
2. 函数图像是输入输出配对的点连成的线，直线的陡峭程度叫斜率
3. 导数 = 曲线上某一点的瞬时陡峭程度 = 汽车速度表读数
4. 三条求导法则：常数导数为 0、线性导数是斜率、幂法则 $x^n \to n x^{n-1}$
5. 链式法则"外层导数乘内层导数"，是将来反向传播的数学基础

下一章你会认识一种新的数学对象：它不是单个数字，而是**一串数字**。你即将发现，一层神经元的全部计算，可以压缩成一次"表格乘法"。
